# Vorbis header sets

`vorbis_headers.bin` holds the Vorbis header packets (identification, comment, setup) that Warframe's Vorbis sounds are encoded against. The game stores its sounds without them, so wfscan needs them to decode a sound or write it as an `.ogg`.

They are not taken from the game. They are what the libvorbis 1.3.7 encoder writes for `vorbis_encode_init_vbr` at 12 combinations of channel count, sample rate and quality, generated by `tools/vorbis-headers` (which compiles libvorbis 1.3.7 from source through the `vorbis-sys` crate). The game's executable holds the same 12 sets, byte for byte: `tools/vorbis-headers --check GAME.exe` compares them, and wfscan-core's real-cache sound test fails if a game update adds a set that isn't here.

The codebooks in the setup packets are part of libvorbis, which is under the BSD 3-clause license in `COPYING-libvorbis` (compatible with wfscan's GPL).

Format: `WFVORBIS`, a little-endian u32 count, then per set the encoder quality x 1000 as an i32 and the three packets, each behind a u32 length. 46,137 bytes, SHA-256 `a49e8b84f12e18ac0d21d6193bc3adc91dfc68f3847b856841f554ebcb05252a`.

To regenerate:

```text
cd tools/vorbis-headers
cargo run --release -- ../../crates/wfscan-core/data/vorbis_headers.bin --check "<game folder>/Warframe.x64.exe"
```
